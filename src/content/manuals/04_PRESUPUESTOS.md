# Manual de usuario: presupuestos

**Aplicación:** ZagaPro / MasterTouch  
**Módulo:** Presupuestos  
**Versión:** 1.0  
**Última revisión:** 5 de octubre de 2026

## 1. ¿Para qué sirve un presupuesto?

El presupuesto permite presentar al cliente una estimación de trabajos, materiales y precios antes de iniciar la reparación. Posteriormente puede:

- Editarse.
- Firmarse como aceptado.
- Imprimirse.
- Rechazarse.
- Convertirse en preorden u orden de trabajo.

## 2. Acceder al módulo

1. Inicia sesión y comprueba el taller seleccionado.
2. Entra en **Presupuestos**.
3. Se mostrará el formulario y la sección **Presupuestos recientes**.

## 3. Seleccionar cliente y vehículo

### Cliente registrado

1. Utiliza **Buscar cliente registrado**.
2. Busca por nombre, teléfono, matrícula o modelo.
3. Pulsa el cliente correcto.
4. Si tiene varios vehículos, selecciona el correspondiente.

### Cliente o vehículo nuevo

- Pulsa **Registrar nuevo cliente** para utilizar el alta rápida.
- Si el cliente ya está seleccionado, puedes añadirle un vehículo nuevo.
- Guarda el cliente o vehículo antes de terminar el presupuesto para mantener correctamente la relación.

## 4. Datos del presupuesto

### Identificación

- **Número de presupuesto:** puede dejarse vacío para generación automática.
- **Cliente:** obligatorio.
- DNI/NIE/NIF, teléfono, dirección, código postal, población y provincia.
- Clasificación: Particular, Empresa o Compañía de seguro.

### Vehículo

- Matrícula o referencia.
- Marca y modelo.
- Bastidor.
- Fecha de matriculación.
- Motor, KW y CV.
- Combustible.
- Kilometraje.

### Datos generales

- Fecha del presupuesto.
- Tipo de operación.
- Estado.

Estados disponibles:

- **Pendiente:** todavía no existe una decisión del cliente.
- **Aprobado:** el cliente acepta el presupuesto.
- **Rechazado:** el cliente no lo acepta.
- **Convertido:** ya generó un documento de trabajo.

## 5. Añadir trabajos y servicios

### Servicio frecuente

1. Abre **Agregar servicio frecuente**.
2. Selecciona un servicio.
3. Se añadirá una línea al presupuesto.
4. Completa tiempo o cantidad y precio.

Para crear una nueva opción reutilizable:

1. Escribe el nombre en **Nuevo servicio frecuente**.
2. Pulsa **Guardar servicio**.
3. La línea se añadirá al presupuesto y quedará disponible para el futuro.

### Línea manual

Pulsa **Agregar línea** y completa los datos mostrados:

- Código y sección, cuando estén disponibles.
- Descripción.
- Tiempo o cantidad.
- Precio unitario.
- Descuento.
- IVA.

### Repuestos

1. Busca la pieza en el bloque **Repuesto**.
2. Selecciona el artículo correcto.
3. Pulsa **Agregar**.
4. Revisa cantidad y precio de venta.

El total presupuestado se actualiza automáticamente. Para retirar una línea utiliza su icono de papelera.

## 6. Observaciones

Utiliza **Observaciones** para aclaraciones del presupuesto, condiciones o notas necesarias. Evita incluir información interna que no deba aparecer en documentación entregada al cliente.

## 7. Crear el presupuesto

1. Selecciona cliente y vehículo.
2. Revisa fecha, tipo de operación y estado.
3. Añade servicios, mano de obra y repuestos.
4. Comprueba cantidades, precios, descuentos e IVA.
5. Revisa el **Total presupuestado**.
6. Pulsa **Crear presupuesto**.
7. Comprueba el mensaje **Presupuesto registrado correctamente**.

El botón **Cancelar** limpia el formulario sin guardar.

## 8. Buscar presupuestos

En **Presupuestos recientes** puedes buscar o filtrar por:

- Matrícula.
- Texto disponible en el buscador.
- Rango de fechas, cuando se muestre.

Cada tarjeta informa de:

- Número de presupuesto.
- Matrícula, marca y modelo.
- Estado.
- Cliente.
- Trabajo.
- Total.

## 9. Editar o eliminar

- Pulsa **Editar** para cargar el presupuesto en el formulario.
- Realiza los cambios y pulsa **Actualizar presupuesto**.
- Pulsa **Eliminar** para retirar el presupuesto, confirmando la operación.

Antes de eliminar, comprueba que no sea el documento correcto de otro cliente o vehículo.

## 10. Firma de aceptación

Si las firmas digitales están activadas:

1. Localiza el presupuesto.
2. Pulsa **Firmar aceptación**.
3. Solicita al cliente que revise el documento.
4. El cliente firma en el dispositivo.
5. Guarda la firma.
6. La tarjeta mostrará **Firmado**.

La firma acredita la aceptación registrada en el sistema, pero no sustituye las revisiones legales o comerciales que correspondan al taller.

## 11. Imprimir

1. Pulsa **Imprimir presupuesto**.
2. Revisa datos del taller, cliente y vehículo.
3. Comprueba líneas, impuestos y total.
4. Imprime o guarda el documento en PDF.

Haz esta revisión antes de enviarlo al cliente.

## 12. Convertir el presupuesto

El resultado depende de la configuración del taller.

### Si las preórdenes están activadas

1. Pulsa **Convertir en preorden**.
2. El sistema creará una preorden vinculada.
3. Pulsa **Completar preorden**.
4. Añade recepción, fotos y firma si corresponde.
5. Desde la preorden podrás crear la orden definitiva.

### Si las preórdenes no están activadas

1. Pulsa **Convertir en orden**.
2. El sistema creará directamente la orden de trabajo.
3. Consulta la orden creada desde el enlace mostrado.

No vuelvas a convertir un presupuesto que ya muestra **Orden creada** o **Completar preorden**.

## 13. Errores frecuentes

- **No aparece el formulario completo:** selecciona un cliente o abre el alta rápida.
- **Cliente duplicado:** busca por teléfono o matrícula antes de registrar uno nuevo.
- **Total incorrecto:** revisa cantidad, tiempo, precio, descuento e IVA de cada línea.
- **No aparece la firma:** comprueba que el módulo de firmas digitales esté activado.
- **No aparece Convertir en orden:** con preórdenes activadas, el flujo correcto es convertir primero en preorden.
- **No puedo convertir de nuevo:** el presupuesto ya está vinculado a una preorden u orden.
- **No encuentro un presupuesto:** limpia la búsqueda y revisa las fechas aplicadas.

## 14. Buenas prácticas

- Identificar correctamente cliente y vehículo.
- Describir cada trabajo en una línea separada.
- Separar mano de obra y repuestos.
- Utilizar cantidades y tiempos reales estimados.
- Revisar precios, descuentos e IVA antes de imprimir.
- Mantener actualizado el estado del presupuesto.
- Obtener firma de aceptación cuando el procedimiento del taller lo requiera.
- Convertir siempre desde el presupuesto original para conservar la trazabilidad.

## 15. Resumen rápido

1. Entra en **Presupuestos**.
2. Selecciona cliente y vehículo.
3. Añade servicios, mano de obra y repuestos.
4. Revisa el total.
5. Pulsa **Crear presupuesto**.
6. Imprime y solicita aceptación.
7. Guarda la firma si corresponde.
8. Convierte en preorden u orden según la configuración.
