# Manual de usuario: preórdenes de trabajo

**Aplicación:** ZagaPro / MasterTouch  
**Módulo:** Preórdenes  
**Versión:** 1.0  
**Última revisión:** 5 de octubre de 2026

## 1. ¿Para qué sirve una preorden?

La preorden documenta la recepción inicial del vehículo antes de crear la orden de trabajo definitiva. Permite registrar:

- Cliente y vehículo.
- Fecha de recepción y entrega prevista.
- Motivo indicado por el cliente.
- Tipo de operación.
- Tiempo estimado.
- Fotos de recepción, si el módulo está activado.
- Firma de recepción, si las firmas digitales están activadas.
- Resguardo para el cliente.

## 2. Acceder al módulo

1. Inicia sesión y comprueba el taller seleccionado.
2. Desde el menú principal entra en **Preórdenes** o pulsa **Nueva preorden**.
3. Se abrirá el formulario **Nueva preorden** y, debajo, las preórdenes recientes.

## 3. Seleccionar cliente y vehículo

### Cliente registrado

1. Escribe en **Buscar cliente registrado**.
2. Puedes buscar por nombre, teléfono, matrícula o modelo.
3. Pulsa el cliente correcto.
4. Si tiene varios vehículos, selecciona el vehículo correspondiente.
5. El sistema cargará sus datos automáticamente.

> Comprueba siempre matrícula y modelo antes de continuar.

### Cliente nuevo

1. Pulsa **Registrar nuevo**.
2. Completa los datos del cliente y del vehículo.
3. Pulsa **Guardar cliente nuevo**.
4. El cliente quedará registrado y cargado en la preorden.

### Vehículo nuevo para un cliente existente

1. Selecciona el cliente.
2. Pulsa **Agregar otro vehículo**.
3. Completa sus datos.
4. Pulsa **Guardar vehículo en cliente**.

## 4. Datos de la preorden

### Cliente

| Campo | Obligatorio | Observación |
|---|:---:|---|
| Cliente | Sí | Nombre del cliente. |
| DNI/NIE | No | Documento identificativo. |
| Teléfono | No | Recomendado para avisos posteriores. |
| Clasificación | No | Particular, Empresa o Compañía de seguro. |
| Dirección, código postal, población y provincia | No | Datos de contacto y documentación. |

### Vehículo

| Campo | Obligatorio | Observación |
|---|:---:|---|
| Matrícula | Sí | Identificador principal. |
| Marca | No | Fabricante. |
| Modelo | Sí | Modelo del vehículo. |
| Bastidor | No | VIN o número de bastidor. |
| Fecha de matriculación | No | Fecha de primera matriculación. |
| Kilometraje | No | Kilómetros en la recepción. |
| Combustible, motor, CV y KW | No | Información técnica. |

### Recepción

| Campo | Obligatorio | Observación |
|---|:---:|---|
| Fecha de recepción | Sí | Por defecto se muestra la fecha actual. |
| Fecha prevista de entrega | No | Compromiso estimado con el cliente. |
| Tiempo estimado | No | Horas aproximadas de trabajo. |
| Tipo de operación | Sí | Por ejemplo, Mecánica o Chapa y pintura. |
| Motivo de recepción | Sí | Lo que comunica el cliente al entregar el vehículo. |

Describe el motivo con claridad. Ejemplo: “El cliente indica ruido al frenar en la rueda delantera derecha”. Evita diagnósticos definitivos si todavía no se ha revisado el vehículo.

## 5. Crear la preorden

1. Selecciona o registra cliente y vehículo.
2. Completa la recepción.
3. Escribe el motivo indicado por el cliente.
4. Revisa matrícula, kilometraje y fechas.
5. Pulsa **Crear preorden**.
6. Comprueba el mensaje **Preorden registrada correctamente**.

El botón **Limpiar** vacía el formulario sin guardar.

## 6. Fotos de recepción

Si el taller tiene este módulo activado:

1. Localiza la preorden en **Preórdenes recientes**.
2. Pulsa **Fotos**.
3. Añade imágenes del estado del vehículo: carrocería, daños, kilometraje u otros elementos relevantes.
4. Comprueba que las fotos aparecen asociadas a la preorden correcta.

Una vez convertida en orden, la carga de nuevas fotos desde la preorden puede quedar bloqueada, aunque las imágenes existentes seguirán disponibles.

## 7. Firma de recepción

Si las firmas digitales están activadas:

1. Pulsa **Firmar recepción**.
2. Entrega el dispositivo al cliente.
3. Solicita que revise y firme la recepción.
4. Guarda la firma.
5. La preorden mostrará **Recepción firmada**.

## 8. Imprimir documentos

Cada preorden ofrece:

- **Imprimir:** documento completo de recepción.
- **Resguardo:** versión destinada al cliente.

Revisa los datos antes de imprimir, especialmente matrícula, fecha, motivo y teléfono.

## 9. Editar o eliminar

Mientras no se haya convertido en orden:

- Pulsa **Editar** para modificarla.
- Pulsa **Eliminar** para retirarla, confirmando la operación.

Las preórdenes convertidas ya no muestran estas acciones porque forman parte del historial de la orden.

## 10. Convertir en orden de trabajo

1. Localiza la preorden.
2. Pulsa **Convertir en orden**.
3. Se abrirá la pantalla de órdenes con los datos ya cargados.
4. Revisa cliente, vehículo, motivo de recepción, fechas y tipo de operación.
5. Añade trabajos, servicios, repuestos y costes.
6. Pulsa **Crear orden**.
7. La preorden quedará marcada como **Convertida**.

Después podrás utilizar **Ver orden** para consultar el documento resultante.

## 11. Buscar preórdenes

El buscador de **Preórdenes recientes** permite buscar por:

- Cliente.
- Matrícula.
- Motivo de recepción.

Utiliza **Anterior** y **Siguiente** para cambiar de página.

## 12. Errores frecuentes

- **No aparece el formulario:** primero busca y selecciona un cliente o pulsa **Registrar nuevo**.
- **Falta matrícula o modelo:** completa ambos campos obligatorios.
- **Falta el motivo:** describe la razón por la que entra el vehículo.
- **Cliente duplicado:** busca por teléfono o matrícula antes de usar el alta rápida.
- **No se pueden añadir fotos:** comprueba que el módulo esté activo y que la preorden no esté convertida.
- **No se puede editar:** la preorden probablemente ya fue convertida en orden.

## 13. Resumen rápido

1. Entra en **Preórdenes**.
2. Busca y selecciona cliente y vehículo.
3. Completa recepción y motivo.
4. Pulsa **Crear preorden**.
5. Añade fotos y firma si corresponde.
6. Imprime el resguardo.
7. Cuando proceda, pulsa **Convertir en orden**.
